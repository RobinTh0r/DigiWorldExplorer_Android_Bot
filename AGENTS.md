# Project handoff

Read `HANDOFF_5.4.1_BETA1.md` before continuing development or device testing. This folder is the authoritative source for `v5.4.1-beta.1`; do not use older sibling worktrees or historical plans as the current implementation. Check `git status` and the connected device before changing or tapping anything. The game terminates with security-policy error `00000038` when tested through ADB on physical phones, so keep USB debugging disabled during phone game runs and use the in-app Experimental diagnostic mode. BlueStacks ADB tests do not prove phone compatibility. Preserve the existing app ID, signing identity, settings, and user data. Do not publish another release without the user's explicit request.
